\# Sistema de Gestión de Concesionario de Autos



\## Descripción

Este proyecto es un sistema de ventas desarrollado para la materia de Base de Datos II. 

Se enfoca en la gestión de inventario, ventas y financiamiento de vehículos.



\## Reglas del Negocio

\- Un cliente puede realizar una o muchas ventas.

\- El stock se actualiza automáticamente al marcar un auto como "vendido".

\- Se soporta pago al contado y planes de financiamiento.



\## Tecnologías Utilizadas

\- \*\*Base de Datos:\*\* PostgreSQL (pgAdmin 4)

\- \*\*Lenguaje de Programación:\*\* Python (próximamente)

\- \*\*Control de Versiones:\*\* Git \& GitHub
